Hardware fixes included

  • Sliding contacts: high-side media power cutoff, active discharge, passive bleed and a separately biased buffer-enable circuit. Both firmware permission and the physical seat/eject loop are required. A broken interlock wire disables the medium.
  • Mechanical sequencing: the short right-side button opens the flap before withdrawing the latch. Standard metal follower screws run in replaceable brass sleeves. Catalog springs, real insert depths, retained pivots and switch-wire paths are modeled.
  • Electrical assembly: through-hole core/dock carriers with socketed Pico 2 H modules, board-mounted external ports, current-limited piezo output, and three through-hole addressable LEDs in a removable holder.
  • Inspection: solder mask covers traces and fills in the preview; exposed pads and leaves remain metallic. All five PCB views include their actual silkscreen. The saved schematic and PCB files, not the rendered colors, define the electronics.

Previous experimental firmware — unchanged

Implemented, not hardware-proven: the core generates 720 KiB / 1.44 MiB PC MFM read pulses using PIO/DMA and always asserts write protection. What a real sample still has to establish

The remaining hardware work is physical qualification: print fit, spring friction and handedness, contact wear, switch adjustment, fastest eject, brownout discharge, supply margins, USB and actual host behavior. Digital checks cannot measure these. Start with a prototype, not a production batch.

PC write capture, IEC drive/DOS behavior and complete emulation profiles remain software work. ESP32 and Spectrum Next use separate host adapters; the accessory connector alone does not make this a native Next floppy interface.
