The four requested changes

  1. Sliding contacts: switched 3.09 V nominal power, four buffered SPI signals, active discharge and a hardware seat/eject permission loop. Core J3 is now seven pins. The loop must open before the latch releases; switch brackets and timing still need physical design and measurement.
  2. Safe eject and recovery: commit-last, CRC-checked sector journal; readback before write success; copy-before-erase garbage collection. Generation-tagged requests reject stale operations after a disk swap. This protects sectors in the tested fault model, not unflushed host caches or entire filesystem transactions.
  3. Power and input defaults: low-voltage-gate MOSFET output drivers replace LS06 chips. Added input bias and buffered power presence. Budget is 0.70 A including a 0.20 A lighting allowance; the supply-margin calculation still requires measured verification.
  4. Routing and firmware: both carrier boards fully routed with ground fills. Two Pico 2 UF2 builds, host-side power-cut tests, MFM tests and transport tests are available below.

Firmware to inspect and test

Implemented, not hardware-proven: the core generates 720 KiB / 1.44 MiB PC MFM read pulses using PIO/DMA and always asserts write protection. The dock implements USB MSC/SCSI removable read/write storage over the journal. USB MSC is not a USB UFI floppy profile. These binaries require controller R1 and dock R3.

Still required before ordering a working-drive prototype

  • Integrate and measure the seat/eject switches, including bounce and fastest eject. The older assembly preview is not proof of this mechanism.
  • Measure supply margins, regulator startup/discharge, cable-loaded MOSFET pulses, USB operation and peer-power-off behavior.
  • Check connector footprints, harness ordering and the moved internal USB connector against the case.
  • Implement PC floppy write capture and IEC/DOS firmware. Validate Windows/Linux USB behavior and named retro hosts on actual hardware.
